How to create a correct Gist
1. Open gist.github.com → New gist → Public
2. Fill .txt file, e.g: STUCK, NOT FOUND / DELIVERED, RECEIVED, SIGNATURE
3. Click Raw → copy URL gist.githubusercontent.com/.../raw/...
4. Don't use gist.github.com HTML page URL, AI cannot read it.

      


      

        
Judge Rules (V5 Final)

        

        RULE 1 - DELIVERED: Seller Gist contains DELIVERED / RECEIVED / SIGNATURE / ARRIVED → Refund 0%


        RULE 2 - LOST: Tracking / Buyer Gist contains STUCK / LOST / NOT FOUND + seller NO_EVIDENCE → Refund 100%


        RULE 3 - INCONCLUSIVE: No clear keyword → Refund 50%


        Why keywords? So all GenLayer validators agree on 1 word, not UNDETERMINED like free-form reasoning.
